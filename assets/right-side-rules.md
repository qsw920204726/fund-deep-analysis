# 右侧交易参数定值

> 用户已确认的参数（2026-08-02 更新：满仓模式）。底仓 40%→满仓 100%，移动止盈 10%→12%。改动前先和用户确认。

## 时间框架

- **主信号：周线**（20 周 / 60 周均线判大趋势）
- **辅助：日线**（找精确买点、突破确认）
- 节奏：持仓数周 ~ 数月（中长线），契合场外基金 T+1 的日级净值

## 四时机信号体系

| 时机 | 触发条件 | 仓位 |
|---|---|---|
| **建仓** | 净值站上 20 周线且拐头向上 + 形成【更高低点】（前低不破）+ 突破平台 + 板块同步右侧共振 | 40% 底仓，主升确认补到 100% |
| | 场内 ETF 额外检测放量（volume_surge ≥1.5 强突破，<1.2 警惕假突破）；场外基金无量，仅价突破 | |
| **加仓** | 回踩 20/60 周线不破（均线买法）or 突破前高放量 | 金字塔 40→35→25%（越加越少） |
| **止盈** | ①跌破 5/10 日线减 30% → ②跌破 20 周线+死叉减 40% → ③跌破 60 周线/上升趋势线清仓；**移动止盈：从阶段高点回撤 12%** | 分 3 档 |
| **止损** | 假突破跌回突破位 / 跌破建仓前低 / 跌破 60 周线+空头排列 | 坚决清仓 |

## 关键参数

| 参数 | 值 | 含义 |
|---|---|---|
| `FAST_WEEKS` | 20 | 主趋势均线（周） |
| `SLOW_WEEKS` | 60 | 长期趋势均线（周） |
| `TRAILING_STOP_PCT` | 0.12 | 移动止盈回撤阈值（满仓型） |
| `BASE_POSITION` | 0.40 | 右侧底仓 |
| `FULL_POSITION` | 1.00 | 主升浪确认后仓位上限 |
| `TRADING_DAYS` | 252 | 年化交易日 |
| `RISK_FREE` | 0.02 | 无风险利率（夏普/索提诺用） |
| 深度回撤阈值 | -25% | 距阶段高点 < -25% 标记"深度回撤"警告 |

## 板块共振（右侧放大器，Phase 2 接入）

| 板块状态 | 基金右侧信号 | 决策 |
|---|---|---|
| 板块同步上升 🟢 | 基金右侧 | 强确认，可重仓 |
| 板块震荡 🟡 | 基金右侧 | 轻仓试探 |
| 板块走弱 🔴 | 基金右侧 | 警惕假突破，不进或极轻仓 |
| 板块见顶（量价背离） | — | 基金止盈预警（领先信号） |

## regime → 操作映射（脚本决策核心）

| regime | 结构 | 操作 | 仓位 |
|---|---|---|---|
| 下降 | — | 观望·不进场 | 0% |
| 震荡 | 更高低点+突破 | 试探建仓（轻仓） | ~24% |
| 震荡 | 无明确信号 | 观望·等待 | 0% |
| 上升 | 更高低点 | 持有·回踩加仓 | 100% |
| 上升 | 低点待确认 | 持有·暂不加仓 | 40% |
