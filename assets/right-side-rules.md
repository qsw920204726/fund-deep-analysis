# 右侧交易参数定值（v0.5）

> 用户已确认的参数（2026-08-02 更新：满仓模式）。底仓 40%→满仓 100%，移动止盈 10%→12%。
> v0.5（2026-08-05）：新增持仓状态机、量能/板块门控、双日确认、双轨止损、追高上限。

## 时间框架

- **主信号：周线**（20 周 / 60 周均线判大趋势）
- **辅助：日线**（找精确买点、突破确认、快速右侧探针）
- 节奏：持仓数周 ~ 数月（中长线），契合场外基金 T+1 的日级净值

## 四时机信号体系（v0.5）

| 时机 | 触发条件 | 仓位 |
|---|---|---|
| **建仓** | 净值站上 20 周线且拐头向上 + 形成【更高低点】（前低不破）+ 突破平台 + 板块同步右侧共振 | 40% 底仓，主升确认补到 100% |
| | 场内 ETF 额外检测放量：**≥1.5x 强突破，1.2~1.5x 仅 16% 极轻仓，<1.2x 判缩量假突破不进场**；场外基金无量，仅价突破 | |
| | 空仓视角：**回踩 MA20 挂单建仓**，当前价距 MA20 溢价过高（>5%）不追高 | |
| **加仓** | 回踩 20/60 周线不破（均线买法）or 突破前高放量 | 金字塔 40→35→25%（越加越少） |
| | 板块走弱（下降）时：上升趋势也不加仓（共振降权） | |
| **止盈** | ①跌破 5/10 日线（取较高者，先破先减）减 30% → ②跌破 20 周线+死叉减 40% → ③跌破 60 周线清仓；**移动止盈：自入场后峰值回撤 12%**（持仓视角） | 分 3 档 |
| **止损** | **双轨止损**：已确认 swing low 与最新可见低点（近 4 周最低）取低者，跌破且含 1% 缓冲 + 连续 2 日收盘确认 | 坚决清仓 |

## 关键参数

| 参数 | 值 | 含义 |
|---|---|---|
| `FAST_WEEKS` | 20 | 主趋势均线（周） |
| `SLOW_WEEKS` | 60 | 长期趋势均线（周） |
| `TRAILING_STOP_PCT` | 0.12 | 移动止盈回撤阈值（满仓型，自入场后峰值） |
| `BASE_POSITION` | 0.40 | 右侧底仓 |
| `FULL_POSITION` | 1.00 | 主升浪确认后仓位上限 |
| `STOP_BUFFER_PCT` | 0.01 | 止损触发缓冲（跌破止损位 1% 才算破位） |
| `TRIGGER_CONFIRM_DAYS` | 2 | 跌破型位需连续 2 日收盘确认 |
| `VOL_SURGE_CONFIRM` | 1.5 | ETF 放量突破确认阈值（≥1.5 强） |
| `VOL_SURGE_SUSPECT` | 1.2 | ETF 缩量突破警惕阈值（<1.2 判假突破） |
| `MAX_CHASE_PCT` | 0.05 | 回测买入追高上限（价格至多高于 MA20 5%，与卡面"等回踩"对齐） |
| `TRADING_DAYS` | 252 | 年化交易日 |
| `RISK_FREE` | 0.02 | 无风险利率（夏普/索提诺用） |
| 深度回撤阈值 | -25% | 距阶段高点 < -25% 标记"深度回撤"警告 |
| 数据门控 | 150 交易日 | 至少 150 个交易日（MA20w 需约 100 日，MA60w 需约 300 日） |

## 视角（持仓状态机，v0.5）

| 视角 | 建仓/加仓 | 移动止盈基准 | 顶层动作 |
|---|---|---|---|
| **空仓**（默认） | 按信号给回踩建仓位 | 52 周高点回撤 12%（仅参考，不判触发） | 关注 · 等回踩建仓 |
| **持仓**（`--state holding --entry <成本> [--peak <峰值>]`） | 不重复建仓 | **入场后峰值**回撤 12%（动态跟踪） | 持仓管理 · 按退出位执行 |

## 板块共振（右侧放大器，v0.5 真正接入决策）

| 板块状态 | 基金右侧信号 | 决策（v0.5 生效） |
|---|---|---|
| 板块同步上升 🟢 | 基金上升 + 更高低点 | 强确认，目标 100%，回踩加仓 |
| 板块震荡 🟡 | 基金上升 + 更高低点 | 目标 60%，轻加仓 |
| 板块走弱 🔴 | 基金上升 + 更高低点 | **降权目标 40%，加仓暂不建议** |
| 板块上升先行 | 基金震荡 + 日线 MA5>MA10 且自 20 日低点反弹 ≥3% | **板块先行 · 轻仓关注 16%** |
| 板块见顶（量价背离） | — | 基金止盈预警（领先信号） |

## regime → 操作映射（脚本决策核心，v0.5）

| regime | 结构 | 操作 | 仓位 |
|---|---|---|---|
| 下降 | — | 观望·不进场 | 0% |
| 震荡 | 更高低点+突破（ETF 需放量 ≥1.2） | 试探建仓（轻仓） | 16~24% |
| 震荡 | 更高低点+突破但缩量（ETF <1.2） | 观望·缩量假突破 | 0% |
| 震荡 | 板块上升先行 + 日线转多 | 板块先行·轻仓关注 | 16% |
| 震荡 | 无明确信号 | 观望·等待 | 0% |
| 上升 | 更高低点 | 持有·回踩加仓（板块降权见上） | 40~100% |
| 上升 | 低点待确认 | 持有·暂不加仓 | 40% |

## 退出触发（v0.5）

- 所有跌破型位（止盈①②③ / 移动止盈 / 止损）需**连续 2 日收盘**确认；
- 止损额外要求低于止损位 **1%** 缓冲，避免贴线误触；
- 移动止盈：持仓视角自入场后峰值动态跟踪；空仓视角仅显示 52 周高点参考位。
