# Task 2 · 风险收益指标公式

> 全部基于日净值（unit_nav）序列计算。年化用 √252 交易日。

## 指标定义

| 指标 | 公式 | 说明 |
|---|---|---|
| 日收益率 | `daily_return/100`（接口已给）或 `unit_nav.pct_change()` | 百分比转小数 |
| 最大回撤 | `(price - cummax)/cummax` 的最小值 | 峰到谷最大跌幅 |
| 当前回撤 | 最后一日相对最近峰值的回撤 | 判断是否还在深谷 |
| 年化收益率 | `(1 + 总收益)^(1/年数) - 1`，年数=交易日/252 | 复合年化 |
| 年化波动率 | `日收益.std × √252` | 总风险 |
| 夏普比率 | `(年化收益 - 无风险) / 年化波动` | 无风险=2% |
| 索提诺比率 | `(年化收益 - 无风险) / 下行波动` | 只算负收益的波动 |
| 卡玛比率 | `年化收益 / |最大回撤|` | 回撤调整后收益 |

## 多周期收益

近 1月(21交易日) / 3月(63) / 6月(126) / 1年(252) / 3年(756) / 成立以来。

## 实测样例（161725 白酒，2026-07-24）

- 最大回撤 **-69.88%**（2021-06-07 → 2026-07-09）
- 年化波动 30.97%，夏普 -0.244，卡玛 -0.08
- 距阶段高点 -34.89%（深度回撤）

## 边界处理

- 数据 < 2 条 → 指标返回 None，不报错
- 波动=0 或回撤=0 → 夏普/卡玛返回 None（避免除零）
