# Task 5 · 右侧决策系统详解（skill 灵魂）

> 参数定值见 `assets/right-side-rules.md`。本文件讲决策逻辑。

## 趋势判定（trend_signals.detect_trend）

基于**周线** 20/60 周均线：

- **上升**：价格 > ma20w > ma60w（多头排列）且 ma20w 近 3 周斜率向上
- **下降**：价格 < ma20w < ma60w（空头排列）且斜率向下
- **震荡**：其他

辅助信号：
- **更高低点**（higher_lows）：最近两个 swing low 后者更高 → 企稳结构
- **突破**（breakout_daily）：日净值突破近 60 日高点 → 启动信号
- **金叉/死叉**：ma20w 上/下穿 ma60w（近 4 周内）

## 决策矩阵（right_side_engine.decide）

| regime | 结构信号 | action | 仓位 | 入场位 |
|---|---|---|---|---|
| 下降 | — | 观望·不进场 | 0% | —（不给） |
| 震荡 | 更高低点 + 突破 | 试探建仓（轻仓） | ~24% | ma20w |
| 震荡 | 无 | 观望·等待信号 | 0% | ma20w（备选关注） |
| 上升 | 更高低点 | 持有·回踩加仓 | 100% | 已建仓，加仓=ma20w |
| 上升 | 低点待确认 | 持有·暂不加仓 | 40% | 已建仓，加仓=ma60w |

## 四档净值位（始终计算，供已持有者参考）

- **止盈①**：跌破 5/10 日线 → 当前价 ×0.97（近端支撑近似，减 30%）
- **止盈②**：跌破 20 周线 → ma20w（减 40%）
- **止盈③**：跌破 60 周线 → ma60w（清仓）
- **移动止盈**：stage_high_52w × 0.88（从高点回撤 12% 清仓）
- **止损**：recent_swing_low（跌破前低清仓）

## 关键设计原则

1. **下降趋势绝不给建仓位**——这是右侧第一条纪律，硬编码在 decide() 里。
2. **建仓/加仓位在"不进场"时显示 —**，逻辑自洽（不进场就没有入场点）。
3. **止盈止损始终给**——即使用户不进场，若已持有，要知道在哪撤。
4. **深度回撤警告**：距阶段高点 < -25% 标记，提示"飞刀风险"。
5. **agent 可覆盖**：板块见顶预警等定性因素，agent 写 action_override 降仓。

## Agent 介入要点（深度模式）

读 rightside.json 后判断：
- 这是**主升浪**还是**反弹**？（主升浪才值得重仓，反弹只能轻仓）—— Phase 2 板块数据接入后更准
- **风格是否漂移**？（持仓行业是否偏离基金合同）
- 当前净值位相对均线/前低/阶段高点的位置 → 是否在右侧买点
